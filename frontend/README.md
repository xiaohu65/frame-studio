# 帧工坊本地工作台

React + Vite 前端。首次使用和整体启动见[仓库 README](../README.md)。生产文件在 `dist/`，由本地 Python 服务统一提供；接口和媒体均从相同的本机地址读取。

```sh
npm ci
npm run build
```

开发模式 `npm run dev` 只绑定 `127.0.0.1`，将 `/api` 代理到本机 `8765`。无需另外打开浏览器实例。

界面采用五步流程：原片与分段、人物替换、场景与范围、生成视频、结果与导出。第 5 步依次检查原始候选、对照验收并导出完整成片；正式导出只拼接已验收的原始视频流并接回连续原声。上传与付费生成由对应批次的明确确认触发。历史人偶与旧结果保留来源，不能充当当前原始回片验收。

`src/api.js` 封装 API；`src/components/` 分别管理通用控件、媒体/时间轴、流程页面和输出参数/API 设置。

## 主题与组件

界面使用 shadcn/ui（Radix primitives）和 Tailwind CSS v4，主题来自 tweakcn Default。基础组件源码在 `src/components/ui/`；页面布局使用语义 HTML 和 Tailwind，已删除旧主题库与过渡布局适配层。左侧导航使用标准 Sidebar，支持桌面收起。

在 tweakcn 的 Code 面板选择 Tailwind v4，导出主题后，替换 `src/theme.css` 中标注的 `:root` 和 `.dark` 主题变量块。保留该文件的 Tailwind 导入、`@theme inline` 映射及应用语义色扩展。颜色须使用完整 CSS 颜色值（例如 `oklch(...)` 或 `#...`）。主题字体使用 `--font-sans/serif/mono`，圆角使用 `--radius`，新增页面沿用这些语义变量。

成功、警告、错误、媒体舞台、时间轴和屏幕范围标记的颜色统一定义在 `src/theme.css`。人物标识色是项目数据；黑白遮罩的像素含义保持原有逻辑。更换主题后运行 `npm test`、`npm run build`，并在同一个现有浏览器会话中核对五步导航、表单、下拉菜单、弹窗焦点和桌面布局。只验证桌面端，不测试移动端。

主题迁移已通过 147 项测试和生产构建，其中 `tests/themeMigration.test.mjs` 检查旧依赖与适配层、标准组件入口、固定界面配色、页面覆盖标准控件和侧栏导航契约；遮罩像素测试验证提示色跟随传入主题，并保留原始像素及保护层优先级。桌面检查覆盖五步导航、侧栏收起展开、折叠控件、标签页、下拉菜单及弹窗焦点恢复。验证未触发付费生成或上传；真实云端生成及全部媒体组合不属于本次主题验证。`scripts/check-contract.jsx` 仍可用于组件契约检查，需先启动后端。
