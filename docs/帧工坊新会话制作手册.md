# 帧工坊新会话制作手册

帧工坊用于核对原片和参考素材、提交 Wan3、检查原始返回，以及把已通过验收的原始片段按原定切点拼接并添加音频。目标是 **Wan3 首轮原始输出过关**。制作开始前明确替换对象、应保留的画面和动作，以及交付规格。

新版第 5 步依次执行「检查原始候选」「对照验收」「导出完整成片」。若页面仍显示候选适配或检查并合成，先停止交付并交维护会话核对运行版本。

## 在帧工坊操作

### 1 原片与分段

复用现有帧工坊服务和浏览器会话，浏览器操作串行执行。无法复用时说明限制并等待指示。选对项目，核对原片路径、尺寸、画幅、帧率、音轨和音画起点。按原切点记录源帧号、段内时间及每段的用途。生成前已指定保留的原片片段可直接用于拼接，原片内部的切镜、单帧黑场和动作落点照留。

需要用小样核实能力时，选能覆盖本片最难要求的镜头，例如快速口型、手遮脸、转身或两层倒影。小样也按交付标准核对原始返回。能直接用的首轮原始片段可以进入后续拼接，不要求为了正式成片重复生成。

### 2 人物与参考素材

给目标人物固定编号，逐镜确认出画、转背、遮挡、镜中倒影，以及必须原样保留的人物和动物。用一张定妆图锁定身份，按需要补正侧脸、背面和服装细节，注明每张图的用途。静态定妆图提供外观，原片提供本次动作、表情、光线和镜头参考。

### 3 场景与保留范围

逐镜记录保留还是替换场景、目标是谁、哪些画面和物件必须保留。定位框、时间范围、遮挡记录和已有遮罩可以辅助核对目标与提示词。它们不用于回传后的画面裁切或局部合成。手指、镜框、狗群和门缝等交界，应在实际输入和原始返回两端查看。

### 4 提交前逐镜确认

每个镜头写清楚原片时间范围、指定替换对象、保留内容和必须精确对上的动作。明确背景、运镜、光线、口型、手势、步点、镜像身份和前景遮挡的要求。插镜的起止位置和内部切镜也要写清楚。参考图只提供指定外观，镜头与表演以原片为准。

提交前核对实际使用的参考视频、图号顺序、逐镜提示词、模型、输出规格、片段清单和原声参考选项。有口型或音乐卡点要求时，核对原声参考的时间窗及实际上传清单。最终连续原声按原片时间关系接入。

有 Key 时用 Wan3 API，按本次实际准备结果确认估算和预留费用。无 Key 时可用当前可用的素材包流程准备平台输入，并取回平台原始输出。上传和费用按用户已经批准的一批执行。材料、提示词、片段、模型、规格、音频输入和授权费用范围均相符时，直接执行该批。任何影响本次提交的变化都需重新核对并取得对应授权。

### 5 原始结果核对与封装

收到结果后播放和下载云端原始候选，检查实际尺寸、帧率、帧数、时间戳及完整覆盖。需要原声试听时，用同一份原始画面按原始音画关系试听。规格记录、试听与实际效果验收分别核对。

交付只按批准的原定顺序和切点拼接已验收的原始片段，并接入确认的音频。封装保留原始视频流、画面和帧顺序。使用原片连续原声时，保留原音画起点并一次接回。发现原始规格、时长、切点或封装兼容性不符合要求时，停在待处理并记录原因。禁止通过遮罩合成、重绘、逐帧补画、局部替换、插帧、重采样、缩放、裁切、补尾、变速或重编码改变画面来绕过验收。

## 首轮原始输出验收

按实际时间戳对照原片、实际提交的参考视频和云端原始返回。先原速看，再逐帧核对难点和切镜两侧。每项以本次提交前确认的要求为准。

| 检查项 | 通过条件 |
| --- | --- |
| 人物与外观 | 指定人物、服装、镜像身份正确。其他人物、动物和指定物件保留 |
| 表演与口型 | 对应时刻的眼神、开合口、闭唇、停顿、手势、脚步和接触点符合原片要求 |
| 镜头与场景 | 机位、运镜、构图、背景、明暗变化和出画关系符合逐镜约定 |
| 切点与卡点 | 原定切点、保留插镜及内部切镜完整，画面动作与音乐重拍对应 |
| 遮挡 | 手、头发、眼镜、道具、衣袖、动物与门等前后关系正确 |
| 规格与原声 | 文件规格、时间覆盖和拼接条件符合约定，试听可核对音画起点和连续原声 |

任何硬要求失败时，本段保留为未通过，记录段名、源帧、段内时刻、预期和原始返回的实际画面。原始候选留作证据，禁止用修补或覆盖把失败隐藏在交付文件中。保持停止交付状态，待用户决定是否调整输入并授权新批次。正式验收以用户确认及对应记录为准。

## 异常处理与交接

原始返回若换错人物、改写动作或口型、漏掉插镜、错切、改背景或弄错遮挡，先核对冻结的实际输入，指出原始结果中的具体问题。另做一批生成需要明确的新授权。遇到鉴权、权限、限流、任务状态未知或下载失败，先保存任务编号和错误，再查询或恢复原任务。查询和下载属于同一任务的恢复。

若 `FaceDetectionSuspect` 提示疑似真人输入，保留原始错误和 Request ID，把素材审核与 API 鉴权分别排查。若界面需要运行改变画面的操作才能导出，记录复现步骤、实际结果和所需的原始拼接能力，交给工具维护会话。

交付记录应包含原片、实际提交材料、原始返回、验收结果、拼接顺序、音轨来源和文件实测规格。未通过的候选作为失败证据保留。后续会话引用本手册与已确认的记录，沿用同一验收口径。
