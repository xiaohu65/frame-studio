# Local studio contract

Concept: design/workspace-concept.png. True white/nearblack, blue-indigo #2454ef, thin gray borders, compact Chinese sans UI. Header 64px, workflow rail 220px, central workspace flex min-width0, inspector300px; at <=1100 inspector below main, <=760 workflow horizontal. Media always real project preview, not concept render. Generated concept is not a final puppet quality claim. Inspector strings/values read actual backend; no fake metrics/progress. Native image assets only user's project images.

User flows: 原片与分段 / 关节人偶 / 人物与场景 / 提示词与生成 / 拼接与音乐 / API设置. New project, upload source (binary), edit trim range segments, analyze/render pose and review limitations, upload/import 3 references per role & scene images, package export, prompt edit, 1080P/watermark=false, actual API preflight+budget authorization/manual submit+poll+download, original sound extraction/music separation then timeline assemble/export. Show local statuses and actionable failures. No paid live calls on page load/preflight. Existing seeded A/B are旧版待关节复核 until new refs pass.

Backend API JSON relative /api; all errors {error}. GET /api/state -> {projects:[summary],project:{...},system:{...},config:{configured,source,base_url,workspace_id},jobs:[]}. GET /api/projects/{id}; POST /api/projects {name}; PUT /api/projects/{id} partial editable fields {segments,settings,prompts,roles,scene,authorization}. POST /api/upload?project_id=...&kind=source|reference|music|generated&role=gold|silver|referee|scene&segment_id=A&filename=... (raw bytes Content-Type application/octet-stream). POST /api/projects/{id}/import {path,kind,role?,segment_id?}. Assets are objects {id,name,path,kind,url,thumbnail_url?,meta}. Browser uses url only, server keeps registered path.

Project: {id,name,source:asset|null,source_meta:{duration,width,height,fps,audio},segments:[{id,name,start,end,reference:asset|null,generated:asset|null,status,review_notes}],roles:[{id,name,color,images:[asset],description}],scene:{mode:'preserve'|'replace',images:[],description},prompts:{A:string,B:string},settings:{resolution:'1080P',ratio:'16:9',watermark:false,audio:false,prompt_extend:false},authorization:{mode:'manual'|'agent',budget_yuan:0},music:{asset:null,mode:'original'|'separated'|'custom'},final:asset|null}.

POST /api/projects/{id}/actions {action,segment_id?,...}. Actions: extract_audio; separate_music; package (returns jobId, download asset); analyze_pose; render_puppet; preflight (returns immediate estimate/checks/blockers, does not call paid API); submit (budget_yuan required; only explicit user/agent action); poll (task_id); download (task_id); assemble (use generated segments only; source aligned; music selected; requires unique coverage); save_prompt. POST /api/config {api_key?,base_url?,workspace_id?,persist_key:false} no key returned. GET /api/jobs/{jobid}; polling state every 3s. All processing actions return {job_id,status:'QUEUED'} and local job journal in state. Preflight actual run returns job report same as others? Root will return {job_id} for all actions for frontend consistency. Job {id,action,status:'QUEUED'|'RUNNING'|'SUCCEEDED'|'FAILED'|'NEEDS_REVIEW'|'UNKNOWN',message,result,created_at,updated_at}. Never show SUCCEEDED as quality pass; review explicit.

Every review approval tied to pose/media hash. Any edit invalidates. New source without manual roles cannot be accepted as three-person automatic separation. UI supports user joint editing in dedicated stage if available, otherwise makes NEEDS_REVIEW explicit, no inert generate completion.
